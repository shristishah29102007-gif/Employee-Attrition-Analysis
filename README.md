# Employee-Attrition-Analysis
# Employee Attrition Analysis and HR Retention Dashboard

## Project Overview

This project aims to analyze employee attrition patterns and identify factors that may influence employees to leave an organization. It uses statistical analysis and machine learning techniques to understand employee attrition and support HR retention decisions.

The project will also include an interactive HR dashboard with an employee attrition risk prediction and retention simulator.

## Problem Statement

Analyze overtime, job satisfaction, and tenure drivers using Chi-Square tests and t-tests, train a Logistic Regression model, and develop an HR attrition risk and retention simulator.

## Objectives

- Understand employee attrition patterns.
- Perform data cleaning and exploratory data analysis.
- Analyze relationships between employee characteristics and attrition.
- Apply Chi-Square tests and t-tests.
- Train and evaluate machine learning models.
- Develop an interactive HR retention dashboard.
